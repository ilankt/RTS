## About this guide

The in-game Help button opens a self-contained, illustrated version of this manual that works offline. These wiki pages and the manual share the same explanations and draw costs, stats and hotkeys from the game data.

The Windows beta includes the current unit animations, both factions and age-specific building graphics. AI-assisted development and artwork are part of the project; see the [credits](https://github.com/ilankt/RTS/blob/main/CREDITS.md).
