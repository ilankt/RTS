# Controls and saving

These are the default bindings. Change supported hotkeys in Settings. The command card shows its current shortcuts.

## Selection and camera

- Left-click selects an object. Drag a box to select a group; Shift adds to the selection.
- Right-click issues a context-sensitive order: move, gather, attack, build, repair or worker garrison. Shift + right-click queues supported orders.
- WASD, arrow keys and edge scrolling pan the camera. The mouse wheel zooms. Click the minimap to move the view.
- Ctrl + 1–9 assigns a control group; 1–9 recalls it. Command-card keys are Q, E, R, T on the top row and Z, X, C, V on the bottom row.
- Right-click ground with a production building selected to set its rally point. A resource rally sends newly trained Workers toward that resource.
- Select a foundation to cancel construction for a half refund. Hold Demolish on a completed building to remove it without a refund.

## Save, pause and resume

Esc opens the pause menu. Save and Load use the visible slots; F5 quick-saves to slot 0 and F9 loads it. You can also load from the main menu. Delete a save only if you intend to lose it: deletion requires a second confirmation.

Saves preserve the map, units, economy, ages, upgrades, queues, fog and worker jobs. Immediate combat targets and paths are reconstructed after loading, so units may briefly reconsider their movement.

Installed and portable Windows builds keep saves and settings in %LOCALAPPDATA%\RTS. Updating or uninstalling the game keeps those files. Source runs keep local user files in the source folder. Older saves are migrated when loaded.

The Help button in the main menu or pause menu opens this manual in your default browser. It works offline and does not require a login.

| Key | Action |
|---|---|
| F1 | Select / cycle idle Workers |
| F2 | Select all military production buildings |
| HOME | Jump to your main base |
| TAB | Cycle army units (or swap Worker build tabs) |
| S | Cycle stance |
| F | Cycle formation |
| B | Set camera bookmark |
| N | Cycle camera bookmarks |
| L | Open event log |
| F5 | Quick-save to slot 0 |
| F9 | Load slot 0 |
| [ | Reduce game speed |
| ] | Increase game speed |
